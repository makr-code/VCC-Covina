## 🎯 Key Features (v4.0.2)

### EventBus Architecture

**Central Event System:**
- 30+ event types
- Topic-based subscriptions
- Thread-safe
- ~12ms latency

**Example:**
```python
# Emit event
event_bus.emit(
    EventType.SIDEBAR_LEFT_NAVIGATE,
    {"view": "Home"},
    source="SidebarLeft"
)

# Subscribe
event_bus.subscribe(
    EventType.SIDEBAR_LEFT_NAVIGATE,
    self._on_navigate
)
```

### ViewManager System

**Dynamic View Switching:**
- 10 registered views
- Lazy loading
- Lifecycle management (activate/deactivate/refresh)
- ~0.12ms switch time (4000× faster than v3)

**Example:**
```python
# Switch view
view_manager.switch_view("home")  # ~0.12ms

# Current view
current = view_manager.get_current_view()  # "home"
```
