# Covina Compliance & Automation

Compliance-Management und Automatisierungsplattform

## 📋 Übersicht

**Zweck:** DSGVO-Compliance, Dokumentenverwaltung und Workflow-Automation

**Technologie-Stack:**
Python, FastAPI, React, Docker, ChromaDB, LLM Integration

## ✨ Hauptfunktionen

- Compliance-Prüfungen (DSGVO)
- Dokumenten-Ingestion und -Verarbeitung
- AI-basierte Analyse
- Workflow-Automation
- Dashboard und Reporting

## 🚀 Schnellstart

```bash
# Repository klonen (falls eigenständig)
git clone https://github.com/makr-code/VCC-Covina.git
cd VCC-Covina

# Abhängigkeiten installieren
pip install -r requirements.txt

# Anwendung starten
python main.py  # oder entsprechendes Start-Skript
```
